## Contexto

Attendv / Betek necesitaba una plataforma web para conectar usuarios con servicios bajo demanda, con requisitos de interacción dinámica en tiempo real y buen posicionamiento orgánico.

## Problema

- No existía una base de código para la plataforma: había que construirla desde cero.
- El rendimiento y SEO eran críticos para adquisición de usuarios vía búsqueda orgánica.
- El equipo desplegaba manualmente, generando fricción y errores en release.

## Solución

- Desarrollé la aplicación web completa con React y Firebase, implementando funcionalidades dinámicas (actualizaciones en tiempo real, gestión de solicitudes de servicio).
- Optimicé rendimiento y SEO mediante code splitting, lazy loading y buenas prácticas de metadata/semántica HTML.
- Configuré pipelines de CI/CD, automatizando build, testing y despliegue.

## Resultado

- Mejora medible en velocidad de carga y visibilidad en buscadores.
- Flujo de despliegue automatizado, eliminando pasos manuales propensos a error.
- Base de código mantenible para iteración continua del producto.
