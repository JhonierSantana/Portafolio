## Contexto

Holberton School es un programa intensivo full-stack basado en proyectos reales, cubriendo el ciclo de vida completo del desarrollo de software: desde algoritmos base hasta aplicaciones desplegadas.

## Problema

- El programa exigía construir aplicaciones full-stack completas en ciclos cortos, sin frameworks de andamiaje predefinidos.
- Cada proyecto requería diseñar la arquitectura backend (Flask + MySQL) y frontend (React) desde cero.
- Se exigía cobertura de pruebas unitarias e integración para cada entrega.

## Solución

- Construí múltiples proyectos full-stack usando React para el frontend, Flask para la API y MySQL como base de datos.
- Apliqué pruebas unitarias y de integración en cada proyecto para garantizar calidad y robustez del código.
- Resolví más de 100 ejercicios de algoritmos y estructuras de datos, reforzando fundamentos de resolución de problemas aplicados al diseño de las aplicaciones.

## Resultado

- Certificación en Desarrollo de Software.
- Base sólida en fundamentos de ingeniería de software aplicada directamente en proyectos profesionales posteriores.
