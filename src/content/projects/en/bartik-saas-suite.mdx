## Context

Seguridad Penta / Bartik runs a suite of 5 applications (web, mobile and desktop) used internally for critical operational workflows. The suite carried technical debt and inconsistent UX across platforms.

## Problem

- Key workflows had high friction, hurting internal adoption.
- 4 SaaS applications with no defined frontend architecture, making new features hard to scale.
- Outdated dependencies creating security risk and intermittent bugs.

## Solution

- Led the UX/UI redesign across all 5 applications, prioritizing consistent interaction patterns across web, mobile and desktop.
- Designed and implemented the frontend architecture for the 4 SaaS applications, integrating REST APIs with a clear separation of layers (UI, state, data).
- Directed the migration and update of critical dependencies, running cross-platform functional testing to validate stability.

## Result

- Higher usability and reported user satisfaction across redesigned workflows.
- Reduced technical debt after the dependency migration.
- Reusable architecture foundation for the team's future SaaS applications.
