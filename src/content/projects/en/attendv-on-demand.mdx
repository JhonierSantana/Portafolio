## Context

Attendv / Betek needed a web platform connecting users with on-demand services, requiring real-time dynamic interaction and strong organic search positioning.

## Problem

- No existing codebase — the platform had to be built from scratch.
- Performance and SEO were critical for user acquisition through organic search.
- The team was deploying manually, causing friction and release errors.

## Solution

- Built the complete web application with React and Firebase, implementing dynamic features (real-time updates, service request management).
- Optimized performance and SEO through code splitting, lazy loading and proper metadata/HTML semantics.
- Set up CI/CD pipelines, automating build, testing and deployment.

## Result

- Measurable improvement in load speed and search visibility.
- Automated deployment flow, removing error-prone manual steps.
- Maintainable codebase for continuous product iteration.
